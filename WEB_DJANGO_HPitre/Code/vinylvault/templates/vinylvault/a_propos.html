{% blocktranslate %}À propos de VinylVault 🚀{% endblocktranslate %}

{% blocktranslate %}VinylVault, c'est le fier fruit du cours 420-E60-CH PROGRAMMATION WEB ET SÉCURITÉ. C'est l'histoire d'un projet codé avec passion, trois tasses de café de trop, et une quantité industrielle de larmes versées devant une console de débogage à 2 h du matin. Derrière ce nom ultra-stylé qui évoque un coffre-fort hautement sécurisé pour audiophiles d'élite, se cache en réalité un exploit d'ingénierie logicielle (ou presque) destiné à valider notre session sans détruire notre santé mentale.{% endblocktranslate %}

{% blocktranslate %}Notre Stack Technique 🛠️{% endblocktranslate %}

{% blocktranslate %}Pour faire cohabiter la pop de BTS et le mystérieux Super Popo d'Australie, il a fallu déployer l'artillerie lourde :{% endblocktranslate %}

  • {% blocktranslate %}Requêtes SQL malades mentales : Des jointures si complexes entre les tables Albums et Artistes qu'elles font trembler l'intégrité référentielle de notre base de données.{% endblocktranslate %}
  • {% blocktranslate %}Algorithme de Notation Révolutionnaire : Un système ultra-sophistiqué où chaque membre peut coller son propre cinglant 2/5 à Map Of The Soul sans déclencher une cyberattaque des fans de K-Pop (ta note reste la tienne).{% endblocktranslate %}
  • {% blocktranslate %}Gestion des Coups de Cœur : Une variable booléenne, propre à chaque membre, qui active une petite étoile jaune ⭐, développée après seulement 4 heures de combat acharné contre le CSS.{% endblocktranslate %}
  • {% blocktranslate %}Architecture Robuste : Un bouton Modifier, un autre pour Supprimer pis plein d'autres affaires !{% endblocktranslate %}

{% blocktranslate %}Notre Mission Universelle 🌍{% endblocktranslate %}
